⚙️ Configuração da API

Encontre em: sheets.google.com/spreadsheets/d/AQUI/edit
Crie em: console.cloud.google.com → APIs & Services → Credentials
Encontre em: Configurações da agenda → Integrar agenda → ID da agenda. Precisa estar com "Disponibilizar ao público" ativado.
Ver apps-script/SETUP.md para gerar essa URL. Sem isso, o botão "Novo Agendamento" fica desativado.
