📋 As 3 Opções de CRM

1️⃣ GOOGLE SHEETS

Formatação Automática

⏱️ 5 minutos

O que faz:

  • Colorir por status
  • Congelar cabeçalho
  • Filtros automáticos
  • Ajustar colunas

Cores:

🟢 Verde = Confirmado
🟡 Amarelo = Pendente
🔴 Vermelho = Não Compareceu
🟫 Bege = Sem agendamento
Como usar:
  1. Abra a planilha Google Sheets
  2. Menu → Extensões → Apps Script
  3. Cole: format-sheets.js
  4. Execute: formatLeadsSheet()
2️⃣ DASHBOARD HTML

CRM Profissional

⏱️ 0 minutos (ou 5 min com API)

O que faz:

  • Visual elegante
  • 4 cartões stat
  • Busca em tempo real
  • Responsivo (mobile)

Versões:

📱 crm-dashboard.html — Demo (simulado)
🔗 crm-dashboard-api.html — Real (com API)
Como usar:
  1. Abra crm-dashboard-api.html
  2. Clique em ⚙️ Config
  3. ID da Planilha + API Key
  4. Pronto! (dados carregam)
🚀 Abrir Dashboard
3️⃣ GOOGLE DATA STUDIO

Relatórios Visuais

⏱️ 30 minutos

O que faz:

  • Gráficos avançados
  • Filtros interativos
  • Tabela interativa
  • Totalmente automático

Inclui:

📊 4 cards (estatísticas)
📋 Tabela (com filtros)
🥧 Pizza (distribuição)
📈 Barras (origem)
Como começar:
  1. datastudio.google.com
  2. Criar → Relatório em branco
  3. Conectar planilha
  4. Siga guia em GOOGLE-DATA-STUDIO-SETUP.md
